# ⚖️ 세무·조세 판례 및 예규 실시간 AI 검색 시스템

대한민국 국가법령정보센터 및 국세법령정보시스템의 실제 전국 판례·결정례 DB를 실시간 검색하고, ChatGPT Enterprise(Azure OpenAI / GPT-4o)가 대형 회계법인(삼일·삼정 등) 조세불복 파트너 수준으로 심층 분석 리포트를 제공하는 회계·세무 실무자용 웹 애플리케이션입니다.

---

## 📌 주요 핵심 기능

1. **실시간 전국 판례/결정례 검색**
   - 국가법령정보센터 공식 Open API 연동 (환경변수 `LAW_API_KEY` 기반 보안 연동)
   - 키워드(예: `가지급금`, `감가상각`, `대손금`, `부당행위계산` 등) 입력 시 전국 조세 판례 실시간 수집
   - 사건명, 사건번호, 선고일자, 법원/처분청, 출처 자동 정리

2. **ChatGPT Enterprise / GPT-4o 전문 분석 및 환각 방지 검증**
   - **관련 세법 조항 명시**: 법인세법, 국세기본법, 상증세법 등 구체적 조문 번호 적시
   - **공식 DB 인용 검증(Anti-Hallucination)**: AI가 임의로 사건번호를 날조하지 못하도록 실제 검색된 `matched_cases` 내 사건만 인용 검증
   - **국세청 과세 논거 vs 납세자 방어 논리**: 2단 비교로 쟁점 대조
   - **법원/심판원 최종 판단 기준**: 판결 요지 및 핵심 사유
   - **회계·세무팀 실무 액션 플랜**: 회계 분개 유의사항 및 세무조사 대비 4대 필수 증빙 목록 체크리스트

3. **🔒 사내 보안 로그인 게이트키퍼 (Gatekeeper SSO)**
   - 외부 클라우드 배포 시 비인가자 접근을 원천 차단하는 아이디/비밀번호 인증 시스템
   - 인증 완료 전에는 사이드바 및 본문 코드 일체 차단 (`st.stop()`)
   - 무차별 대입 공격(Brute-force) 지연 방어 및 세무팀 관리자(`admin`) / 실무자(`user`) 역할 분리

4. **💾 클라우드 데이터 영속성 백업 및 원클릭 복원**
   - 시스템 설정 화면에서 현재 축적된 검토 이력 DB(`review_history.db`)와 관심 보관함을 ZIP으로 원클릭 백업 다운로드
   - 클라우드 컨테이너 재시작 시 관리자 권한으로 언제든 즉시 원상 복원 가능

5. **원문 연계 및 엑셀 다운로드**
   - **[법제처 공식 원문 열기]** 버튼으로 판결문 전체 전문 페이지 새 탭 연결
   - 검색 결과 전체를 클릭 한 번으로 `.xlsx` 엑셀 파일로 다운로드

## 🚀 실행 및 배포 방법

### 🌐 방법 1: 무료 클라우드 배포 (Streamlit Cloud - 24시간 무중단 가동)
사내 서버 권한이 없어도 **Streamlit Community Cloud**를 통해 영구 무료로 24시간 가동되는 사내 세무 비서를 배포할 수 있습니다.
- 상세 배포 절차는 [**docs/FREE_CLOUD_DEPLOY_GUIDE.md**](docs/FREE_CLOUD_DEPLOY_GUIDE.md)를 참고해 주십시오.
- **초기 테스트 계정**:
  - 관리자 계정: `admin` / `cj_tax_admin_2026!`
  - 실무자 계정: `user` / `cj_freshway_2026!`

### 💻 방법 2: 로컬 안전 전용 실행 (`run_local.bat` - 사내 기본 권장)
- 프로젝트 폴더 내 **`run_local.bat`** 파일을 더블클릭합니다.
- 내 컴퓨터(`http://localhost:8501`)에서만 열리며, 외부 인터넷망에 일체 노출되지 않습니다.

### 🔗 방법 3: 임시 외부 공유 실행 (`run_share.bat`)
- 사내 보안정책 확인 후 Cloudflare Tunnel 기반 임시 링크를 생성하여 테스트합니다.

## 📂 파일 구성 안내

| 파일명 | 설명 |
| :--- | :--- |
| **`app.py`** | Streamlit 기반 반응형 웹 대시보드 메인 엔트리포인트 |
| **`components/auth.py`** | 보안 로그인 인증 및 접근 제어 게이트키퍼 모듈 |
| **`services/backup_service.py`** | 데이터 백업(Export) 및 복원(Import) 영속성 서비스 |
| **`views/view_settings.py`** | 기준세율 관리 및 데이터 백업/복원 통합 설정 화면 |

| **`config.py`** | 환경변수(.env) 보안 로더, 사용자 인증 및 데이터 경로 추상화 모듈 |

| **`.streamlit/config.toml`** | Streamlit 테마 및 서버 네트워크 최적화 설정 |
| **`.streamlit/secrets.toml.example`** | 클라우드 배포용 암호화 Secrets 설정 템플릿 |
| **`docs/FREE_CLOUD_DEPLOY_GUIDE.md`** | Streamlit Community Cloud 및 Hugging Face 무료 배포 가이드 |
